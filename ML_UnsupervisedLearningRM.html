3) Draw the Elbow curve. What is the best value for k?¶

The elbow curve plot using Distortion, the optimal/best value for K is 3 as the wcss (within-cluster sum of squares) appears to slow down at the elbow bend on 3; i.e, K = 3.

In [47]:
from sklearn.cluster import KMeans

distortions = []
K = range(1, 10)

for k in K:
  kmeanModel = KMeans(n_clusters=k, random_state=21).fit(wholesale_new)
  kmeanModel.fit(wholesale_new)
  distortions.append(kmeanModel.inertia_)

#Elbow plot using distortion
plt.plot(K, distortions, 'bx-')
plt.xlabel('No. of Clusters (k)')
plt.ylabel('Distortion')
plt.title('The Elbow Method showing the optimal k')
plt.show()

6) Write 2 sentences or more about what you can learn from this model.¶

This Unsupervised Learning algorithm or more specifically Kmeans-cluster model defines customers hidden purchase patterns and spending habits.

The elbow plot shows that the best number of clusters is 3, and it is clearly a case of k = 3 due to the distortion reducing sharply at the bend of 3 before it levels off.

From the centroid values, we see that in Cluster 0, "Fresh" has a rather extremely high spending within the customers who focus on that area. Cluster 1 values show that customers spend more money on "Grocery" and "Milk", and then "Detergents_Paper." Finally, Cluster 2 shows the customers in that cluster as being moderate spenders accross all categories of the Wholesale data.

The Clusters and the centroid values give a transparent outlook by separating the customers in a way that shows their spending habits. Overall, from this model we can then form a conclusion on hidden purchasing patterns from wholesale preferences to spending habits. This will help in personalized customer recommendations, predictions and even targeted marketing campaigns; and a bonus in budgeting and resource allocation for grocery/wholesale stores.

All in all, this model shows how we can use raw data to make actionable plans based on customers' purchase/spending patterns. At k = 3, we can say that model results are statistically significant.
